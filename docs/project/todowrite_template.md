# TODOWRITE Template

Use this template when creating `docs/project/Infra-XXX.TODOWRITE.md`.

```
# Infra-XXX: TODOWRITE (Short Name)

**Status**: Active  
**Owner**: Infra

## Purpose
Track top issues discovered during the project.

## Top Issues (Top 30)
- [ ] `path/to/doc.md`: issue summary
```

> **Note**: To close a project, add one entry to [`archive/README.md`](./archive/README.md). Then delete the project file and its TODOWRITE file.
